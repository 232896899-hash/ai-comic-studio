# GitHub 推广文案

## 标题

我做了一个把故事自动变成 AI 短视频的开源工具

## 正文

很多人不是没有故事，而是卡在脚本、画面、配音和字幕同步。

我把这条链路整理成了一个 Remotion 项目：输入故事主题，生成脚本、视觉素材、配音和时间轴，再渲染成适合短视频平台的成片。

目前已支持：

- AI 故事脚本生成
- 图片、配音和字幕时间轴同步
- Remotion 预览和渲染
- 35—60 秒竖屏内容工作流

开源地址：
https://github.com/232896899-hash/ai-comic-studio
