# 10 种 35—60 秒故事结构

1. **误会反转**：主角被误解 → 观众站队 → 证据出现 → 真相反转。
2. **愿望代价**：主角许愿 → 愿望实现 → 代价显现 → 做出选择。
3. **最后一次机会**：倒计时出现 → 连续失败 → 关键线索 → 最后一搏。
4. **弱者救强者**：强者遇险 → 弱者被忽视 → 弱者用独特能力解决问题。
5. **规则陷阱**：主角发现规则 → 试图钻空子 → 规则反噬 → 找到真正解法。
6. **反常日常**：普通场景 → 一个细节不对 → 异常扩大 → 留下第二集钩子。
7. **失而复得**：重要物品丢失 → 追踪线索 → 找到错误答案 → 物品以意外方式回来。
8. **双重身份**：角色隐藏身份 → 任务逼近 → 身份暴露 → 关系重新定义。
9. **一念选择**：两条路摆在面前 → 主角犹豫 → 选择带来即时后果 → 价值反转。
10. **循环一天**：同一天重复 → 主角发现变化点 → 修正一个选择 → 循环结束但留下新问题。
