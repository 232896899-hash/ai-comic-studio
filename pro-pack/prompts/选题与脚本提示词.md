# AI 漫剧 Creator Pro 提示词

## 1. 选题生成

```text
你是短视频编剧。请围绕【主题】生成 10 个适合 35-60 秒竖屏 AI 漫剧的选题。
每个选题必须包含：一句话冲突、主角目标、前三秒钩子、结尾反转、适合的画面风格。
避免空泛鸡汤、未经证实的事实和受版权保护的角色。
```

## 2. 35 秒脚本

```text
把下面的选题写成 35 秒中文短视频脚本：
【选题】
要求：0-3 秒必须有冲突；全片 6 个镜头；每个镜头包含旁白、画面描述、字幕和音效；
旁白总字数控制在 120-150 字；结尾留一个可评论的问题。
```

## 3. 角色一致性

```text
请先建立角色卡，再为每个镜头生成画面提示词。
角色卡字段：姓名、年龄、体型、毛色/发色、服装、标志性道具、性格、固定镜头角度。
每条画面提示词必须完整复述角色卡中的外观要素，不得自行改变服装、颜色或年龄。
```

## 4. 发布改写

```text
把这条脚本改成适合短视频发布的版本，输出：标题 3 个、封面文案 3 个、简介 1 条、
话题标签 8 个、置顶评论 1 条。不得承诺虚假收益，不得使用未授权品牌或人物。
```
