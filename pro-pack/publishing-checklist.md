# 竖屏短视频发布清单

## 内容

- [ ] 前 3 秒出现冲突或问题
- [ ] 画面比例为 9:16，主体没有被字幕遮挡
- [ ] 人物外观在镜头之间保持一致
- [ ] 配音、字幕和画面时间对齐
- [ ] 事实、品牌、音乐和图片来源已核验

## 发布

- [ ] 标题不夸大、不承诺收益
- [ ] 简介说明 AI 辅助创作（如平台要求）
- [ ] 封面只保留一个核心信息
- [ ] 设置评论问题，收集下一集选题
- [ ] 记录平台、发布时间、播放、完播和互动数据

## 复盘

- 3 秒留存低：重写开头冲突。
- 完播低：删掉解释，提前反转。
- 评论低：结尾改成二选一问题。
- 收藏低：增加可复用方法或清单。
